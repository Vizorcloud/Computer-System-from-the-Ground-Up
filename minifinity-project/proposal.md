## Project goals
Stretch Idea: Local Multiplayer Player vs Player functionality with breadboard/software challenges.
Fallback Idea: Monkeytype functionality built on the embedded Pi System

Features:
1. Random text generation
   - database of common words (top 10k)
   - random number generator
2. monkeytype functionality
  - restart
  - live wpm tracker
  - timer.h
  - live accuracy tracker
3. Multiplayer
  - Two keyboards hooked up to the same monitor
  - Split Screen
4. Custom font
5. Swapping Keymaps
6. Using 5-way navigation switch to move punishment explosive onto other persons
7. Punishments/Debuffs
  - Breadboard related challenges
  - Switching keymap of player
  - Changing keys to other ones
  - Disabling keys
